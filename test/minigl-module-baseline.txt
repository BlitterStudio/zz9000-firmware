MiniGL module migration baseline
===============================

Base: origin/feature/app-runtime e727df6f
Recorded from an isolated debian:bookworm-slim ARM-toolchain build and an
isolated ubuntu:24.04 host-test build.  The firmware source and private
library checkout were mounted read-only and copied before either build.

Host regression baseline
------------------------

Commands:
  make -C test/minigl clean test
  make -C test/minigl_v9 clean test
  make -C test/minigl_v9 asan

All three commands exit 0.  CPU raster, polygon, present, lighting, and the
11 RasterIX oracle cases pass (maximum colour difference <= 1; depth exact).
The v9 suite passes its parser/state/draw/texture/host API/card-pool/E2E,
transport guard, RasterIX mapper, and 32-bit guest-client coverage.  The
client summary is `amiberry_v29 DONE 100 0`; `amiberry_ops DONE 96 3` is the
existing host-mock allowance for context-from-bitmap, context-screen-modes,
and texture-packed-565, reported as 0 unexpected failures.

The ASAN/UBSAN command exits 0.  Its pre-existing diagnostics are unaligned
control/status accesses in mw_service.c and its test, unaligned uint32_t
accesses in rix_drv.c, the CSR mock bounds diagnostic in
 test_mw_rasterix_mapper.c, and a signed shift in guest_mock.  These are
recorded here so migration verification compares test outcomes rather than
silencing diagnostics.

The host suites define MINIGL_HOST_TEST, which deliberately compiles the
on-card five-second profiler out; therefore they have no valid profile
counter snapshot.  The module regression target must inject the v3 profile
service and compare its exported counter snapshot, rather than treating a
host-zero counter array as an equivalence measurement.

Resident final-ELF baseline
---------------------------

The unmodified resident link intentionally fails its current 4 MiB high-image
gate, before it can emit an ELF: `ps7_ddr_hi` overflows by 83104 bytes.  This
is the known base failure that the module cutover removes.  Consequently no
truthful final-ELF section table exists at this revision.  The linked-module
measurement supersedes it and is required to report `arm-none-eabi-size -A`
for MINIGL.elf plus the packed MINIGL.ZZM bytes against the 4 MiB slot.
